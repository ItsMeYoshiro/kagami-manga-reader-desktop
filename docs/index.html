Kagami

A manga reader for Windows, built on Mihon's extension ecosystem.

Download for Windows

Windows 10/11 · 64-bit · ~318 MB · source on GitHub

One installer, no Java to set up

Mihon's sources are Android apps. Getting them to run on a desktop normally means installing a JVM, fetching a server, and wiring the two together. Kagami ships all of that inside a single .exe.

Install and open

No Java, no server to configure, nothing to keep running in a terminal.

Pick your sources

The extension repository is already registered — open Extensions and install what you read.

Read

Search across sources, follow titles, download chapters for offline reading.

Before you install

Windows will warn you, and that is expected

The installer is not signed, so SmartScreen shows "Windows protected your PC". Click More info, then Run anyway. Code signing needs a certificate that costs a few hundred dollars a year and has no free tier, so the warning is unavoidable for any independent build.

What is within reach is provenance. Every release is built on GitHub's runners from the tagged commit and carries a signed statement of where it came from. You can check the file before running it, against GitHub rather than against a promise made here: 

gh attestation verify Kagami-0.1.1-x64.exe \
  --repo ItsMeYoshiro/kagami-manga-reader-desktop

How it works

Mihon's extensions are Android apps — DEX bytecode, compiled against the Android APIs. They cannot run on a desktop as they are.

Suwayomi-Server converts them to JVM bytecode and runs them against a compatibility layer that emulates android.*, which is what lets Mihon's own sources work off Android.

Kagami is the client around that: an Electron interface that starts and supervises the server as a child process and talks to it over GraphQL. The JVM is bundled, started on launch and shut down with the app — you never have to know it is there. 

Electron (main)          Electron (renderer)
├─ spawns the JVM   ◄──► ├─ React + TanStack Query
├─ health check     IPC  ├─ GraphQL / graphql-ws
└─ lifecycle             └─ <img> straight at the server
        │
        ▼ spawn
Suwayomi-Server (bundled JRE) → Mihon .apk extensions

Nothing phones home

The bundled server binds to 127.0.0.1. There is no account and no telemetry.

Contributing

The source is on GitHub. It runs from a clone with Node.js 20+ and the Suwayomi bundle next to it. 

git clone https://github.com/ItsMeYoshiro/kagami-manga-reader-desktop.git
cd kagami-manga-reader-desktop
npm install
npm run dev

Full setup · Design notes · Add a language

Adding a language is one new file and one line, and a missing translation fails the type check rather than shipping as the wrong language.

Kagami is MPL-2.0. Mihon is Apache-2.0 and Suwayomi-Server is MPL-2.0 — both independent projects, consumed here, neither affiliated with this one. "Mihon" and its logo belong to the Mihon project.

Kagami hosts no manga and ships no content. It reads from whatever sources you choose to install, and what those sources serve is between you and them. The artwork in the screenshots belongs to its respective creators and publishers, and appears only to show the interface.
